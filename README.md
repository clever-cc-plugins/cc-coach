# cc-coach

A [Claude Code](https://claude.ai/code) plugin bundling live-coaching skills across
job-related and personal-life domains.

**Status: under construction.** This repo currently holds only the design spec —
skills have not been implemented yet. See
[`docs/superpowers/specs/2026-08-18-cc-coach-design.md`](docs/superpowers/specs/2026-08-18-cc-coach-design.md)
for the plan.
