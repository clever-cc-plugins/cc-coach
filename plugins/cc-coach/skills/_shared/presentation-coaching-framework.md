# Presentation Coaching Framework — Shared Reference

Shared reference for `presentation-coach`. Two parts: a rubric for structuring what
to look at, and a feedback model for how to say it.

## Presentation Quality Rubric

**What to assess, in order**

1. **Message clarity** — can the core point be stated in one sentence? If the
   person can't state it in one breath, the talk doesn't have one yet.
2. **Structure** — does it open with something that earns attention (a claim,
   question, or story — not an agenda slide), build in an order the audience can
   follow, and close on the message rather than trailing into Q&A?
3. **Evidence** — are claims backed by something concrete (data, example, story) an
   audience member could later repeat to someone else?
4. **Delivery** — pacing, filler words, eye contact/camera presence, use of pauses.
   Only assess this from what the person actually reports or reads aloud — never
   invent delivery notes for a talk you haven't heard.
5. **Audience fit** — is the vocabulary, depth, and framing right for who's actually
   in the room? If a `personal-branding-strategy` context file is loaded, check the
   talk's message against its Why/How/What — a talk that contradicts the person's
   stated brand themes is a fit problem worth naming.

Work through the rubric in this order — message clarity first, since a structural or
delivery fix on an unclear message just polishes the wrong thing.

## SBI Feedback Model (Situation-Behavior-Impact)

**How to phrase feedback so it's usable, not just true**

What it is: Feedback in three parts — **Situation** (when/where, specific, not
"often"), **Behavior** (what was observed or reported, factual, not a character
judgment), **Impact** (what effect it had or would have on the audience). This
structure keeps feedback actionable instead of vague ("be more confident") or
personal ("you seemed nervous").

How to apply: For each piece of feedback, name the Situation ("In the opening
30 seconds..."), the Behavior ("...you read the agenda slide word for word..."),
and the Impact ("...which meant the audience's attention drifted before you got to
your actual point"). Never skip straight to a verdict without naming the specific
situation and behavior it's based on — a coaching note without SBI shape is a
character judgment, not feedback.

## Persuasion & Pre-Suasion for Live Talks

**How to make the message land, not just be correct**

The Message Clarity and Evidence steps of the rubric establish _what_ the talk
says. This section is about how audiences actually come to believe and act on it —
a live, spoken adaptation of the same research-based persuasion mechanisms
`cc-content`'s `persuasion-principles.md` applies to written content. Use it during
the Evidence and Structure passes of the rubric, and always name the choice rather
than applying it silently — the person coaching a talk needs to understand _why_ a
suggested change works, not just that it does.

**Applying persuasion principles to a talk (not a page):**

- **Reciprocity** — open with something genuinely useful to the audience (a
  reframe, a surprising number, a checklist) before asking for their attention or
  buy-in on the harder point.
- **Commitment & Consistency** — get a small, visible agreement early (a show of
  hands, a rhetorical question the audience silently answers yes to) before the
  talk's larger ask; people who've already nodded once resist the follow-on ask
  less.
- **Social Proof** — named, specific examples ("three teams I've worked with this
  quarter...") land harder live than a claimed statistic the audience can't
  verify in the moment.
- **Authority** — establish it early and specifically (a concrete credential or
  result, not a title recited from a slide), then let it recede — a talk that
  keeps re-asserting authority reads as insecure.
- **Scarcity** — only use this for a talk with a genuine constraint (a real
  deadline, a real capacity limit); audiences read manufactured urgency in a live
  room faster than in text, because they can watch the speaker's certainty.
- **Unity** — strongest live persuasion lever available to a speaker in the room:
  naming the shared context ("everyone in this room has felt...") does more work
  live than it can on a page, because the audience can see each other's reactions
  confirm it.

**Pre-suasive opening (the first 30-60 seconds):** What the audience is attending
to right before the core message lands changes how they interpret it. Before
drafting the opening line, decide what you want the audience primed toward —
a problem (makes the solution feel relevant), a shared identity (makes a Unity
appeal land), a surprising fact (keeps attention open longer) — and open there
rather than with logistics or an agenda slide. Coach the person to state this
choice out loud during rehearsal: "I'm opening with the problem because the
audience needs to feel the stakes before they'll care about the fix."

**Ethical use, live version:** the same two tests from `persuasion-principles.md`
apply, sharpened by the fact that a live audience can see the speaker: would the
audience, fully understanding the technique, still want the outcome? And does the
technique survive the speaker being watched closely while using it? A pre-suasive
opener or an authority claim that only works because the audience can't see the
speaker's face is a text-only tactic — flag it as a bad fit for a live talk rather
than porting it over.
