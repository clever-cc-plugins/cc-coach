# Presentation Coaching Framework — Shared Reference

Shared reference for `presentation-coach`. Two parts: a rubric for structuring what
to look at, and a feedback model for how to say it.

## Presentation Quality Rubric

**What to assess, in order**

1. **Message clarity** — can the core point be stated in one sentence? If the
   person can't state it in one breath, the talk doesn't have one yet.
2. **Structure** — does it open with something that earns attention (a claim,
   question, or story — not an agenda slide), build in an order the audience can
   follow, and close on the message rather than trailing into Q&A?
3. **Evidence** — are claims backed by something concrete (data, example, story) an
   audience member could later repeat to someone else?
4. **Delivery** — pacing, filler words, eye contact/camera presence, use of pauses.
   Only assess this from what the person actually reports or reads aloud — never
   invent delivery notes for a talk you haven't heard.
5. **Audience fit** — is the vocabulary, depth, and framing right for who's actually
   in the room? If a `personal-branding-strategy` context file is loaded, check the
   talk's message against its Why/How/What — a talk that contradicts the person's
   stated brand themes is a fit problem worth naming.

Work through the rubric in this order — message clarity first, since a structural or
delivery fix on an unclear message just polishes the wrong thing.

## SBI Feedback Model (Situation-Behavior-Impact)

**How to phrase feedback so it's usable, not just true**

What it is: Feedback in three parts — **Situation** (when/where, specific, not
"often"), **Behavior** (what was observed or reported, factual, not a character
judgment), **Impact** (what effect it had or would have on the audience). This
structure keeps feedback actionable instead of vague ("be more confident") or
personal ("you seemed nervous").

How to apply: For each piece of feedback, name the Situation ("In the opening
30 seconds..."), the Behavior ("...you read the agenda slide word for word..."),
and the Impact ("...which meant the audience's attention drifted before you got to
your actual point"). Never skip straight to a verdict without naming the specific
situation and behavior it's based on — a coaching note without SBI shape is a
character judgment, not feedback.
