# Career Coaching Framework — Shared Reference

Shared reference for `career-coach`. Baseline framework used whether or not a
`career-plan`/`personal-branding-strategy` context file is loaded — when one is,
its content fills in what would otherwise be asked directly.

## GROW Model

**Structure a coaching conversation from goal to committed action**

What it is: A four-stage conversational structure — **Goal** (what does the person
want from this session, or from the situation they're raising), **Reality** (what's
actually true right now — skills, constraints, prior attempts), **Options** (what
could be done — generated by the person first, coach adds options only after),
**Will** (what will the person actually commit to, by when). The discipline: the
coach asks, the person answers — the coach does not hand the person their own plan.

How to apply:

1. **Goal.** Ask what the person wants from this conversation. If a `career-plan`
   context file is loaded, you may ground this in one of its milestones ("Want to
   work through the milestone about X?") rather than asking cold — but still let the
   person confirm or redirect, don't assume.
2. **Reality.** Ask what's true now relative to that goal — what's been tried, what's
   in the way, what resources exist. If `career-background` context is loaded, note
   it silently rather than re-asking; if not, ask directly here.
3. **Options.** Ask the person to generate options first ("What could you do?")
   before offering any of your own. Once they've generated 1-2, you may add options
   they haven't named — label them clearly as your suggestion, not their idea.
4. **Will.** Ask what they will actually commit to and by when. A vague "I'll think
   about it" is not a Will-stage answer — push once for a specific action and
   timeframe before treating the stage as complete.

When a `personal-branding-strategy` context file is loaded and the goal touches
visibility or positioning, reference its Why/How/What and key themes directly in the
Reality and Options stages rather than asking the person to restate their brand.
